# Administrator helper loader boundary

Windows builds and publishes replace the SDK's managed apphost with `NativeBootstrap.cpp`, compiled by `eng/Build-PrivilegedBootstrap.ps1`. Visual Studio C++ tools and the Windows SDK are required for x64/ARM64 helper builds. A failed native build fails the build/publish; its managed apphost must not be installed as a substitute. Non-Windows solution builds retain the managed assembly for compilation and tests; Windows helper publication requires Windows native tools.

The native executable keeps the existing `requireAdministrator`/Common Controls manifest, icon, version resources, process identity and managed entry point. Before loading a CLR host it resolves the executable, managed DLL/deps/runtimeconfig and host to protected Program Files paths; uses the system working directory and DLL search boundary; removes process-local DOTNET, COMPlus, CORECLR, COR, COREHOST and MONO loader settings; fixes PATH to the system directory and disables CLR diagnostic attachment. Persistent user/machine environment and security settings are untouched. Managed startup-hook support also stays disabled in the protected runtime configuration.

Self-contained publication uses the protected adjacent hostfxr. Framework-dependent publication uses the highest stable hostfxr from the architecture's default protected Program Files .NET installation, with that explicit root passed to hostfxr. This retains runtime servicing for the FDD build. Writable/user-defined runtime roots and preview hostfxr versions are not administrator-helper runtime sources. A missing protected runtime is refused. The application itself can still use its normal supported runtime configuration.

The hostfxr entry point starts the existing managed `Main` in the same process with the original arguments; plan, requester, nonce, displayed consent and operation checks remain there. Native build receipts in the intermediate directory pin source, manifest, icon, resource compiler, C++ compiler and output bytes. Compiler/environment/payload/IPC trust, limited-caller consent and exact installed-candidate qualification remain release gates; this entry point is not a complete security qualification.

Before CLR loading, the bootstrap checks the resolved helper file and every ancestor through its Program Files root. Owners must be SYSTEM, BUILTIN Administrators or TrustedInstaller. An ordinary SID's write, delete, permission-change or owner-change grant is refused; ordinary read/execute access and inherit-only creator-owner rules remain compatible. Unverifiable or unsupported grant forms fail closed. The entire helper directory tree is checked with entry, depth and time bounds, and reparse points are refused, so an ordinary-writable adjacent dependency cannot bypass the entry-file check. The selected hostfxr and its ancestor chain receive the same permission checks.

The caller checks the executable and each ancestor through Program Files before discovery returns it and again before ShellExecute requests elevation. The same owner/writer policy applies. Missing files, reparse points and names that resolve to a different target are refused before Windows can start a replacement executable. The native bootstrap then independently checks the loader tree after startup. Concurrent replacement still requires further qualification.

Framework-dependent startup also checks the default architecture root's complete `shared` framework tree and its ancestors before loading hostfxr. The same ownership, grant, reparse and bounded-walk policy applies, including frameworks/versions that servicing could select. An unverifiable shared runtime is refused; installing a newer administrator-protected runtime remains supported.

These checks do not establish every possible dependency resolution route, eliminate concurrent file replacement, or qualify IPC token/path identity and limited-caller consent. Those remain in the release loader audit. All compiled/runtime components, including native compiler runtime inputs, must complete the release license/provenance inventory.
