# Download FileCat

The [unsigned 1.0.0-preview.3 release](https://github.com/benny-cz/FileCat/releases/tag/v1.0.0-preview.3) provides downloads for Windows, Ubuntu and macOS. It is a preview; stable 1.0.0 is still in validation. Read the [release notes](release/1.0.0/PREVIEW3_RELEASE_NOTES.md) for supported packages and limits, and check the [published asset inventory and SHA-256 hashes](release/1.0.0/evidence/E-PREVIEW3-TAG-20261030.md#exact-hosted-inventory-for-the-separate-public-preview-decision) before installing. The [README](../README.md) describes FileCat's functionality and how to build it from source.

## Code signing policy

The current preview is **unsigned**. FileCat is applying to use SignPath Foundation for code signing future Windows releases. No SignPath acceptance, certificate or signed FileCat package is claimed. If the application is accepted, this page will identify the signed packages and signing policy before they are offered as signed downloads. The proposed credit for that future service is: “Free code signing provided by [SignPath.io](https://about.signpath.io/), certificate by [SignPath Foundation](https://signpath.org/).”

The repository maintainer, [benny-cz](https://github.com/benny-cz), owns source changes and release approval. Signing roles and controls will be published after the provider confirms them. See FileCat's [privacy policy](PRIVACY.md) and [security reporting policy](../SECURITY.md).
