# EFS recovery key evidence in recorded calls

The version-three encryption journal requires the actual reviewed setup key for every encryption intent. It binds that evidence to the same scope consent and records the setup object's identity, invoking SID, certificate thumbprint and recovery choice. The recovery choice records either the user's declared arrangement or Windows' reported private-key export completion. A completed encryption result requires a matching, available current-user key in the observed file association. An unexpected or unresolved result remains review-required and prevents another intent. The existing version-one compression and version-two consent evidence remain readable.

The held EFS adapter supplies typed key observations from the resulting file. The collector bounds those observations, rejects duplicate or malformed hashes and refuses a claimed success with missing or mismatched evidence. Exact call pages and exports retain the reviewed and observed keys. The report labels the source of the recovery choice and the actual observed association separately. These records provide historical evidence only.

Ubuntu and macOS each passed 77 Core journal tests and eight application report tests. The first application package carried a stale report binary and omitted native text-shaping libraries. The corrected packages matched the source and included the runtime libraries. Final XML is under `.tmp/efs-recovery-journal-core/results.xml` and `.tmp/efs-recovery-journal-app-b/results.xml` in both remote test checkouts.

The Windows 11 x64 VM passed 20 cases in the combined setup, key and backup suite, with three conditional skips. The dedicated real key-rotation case also passed. Both the unchanged-key and rotated-key cases flushed an intent and recorded the held native effect through the same version-three writer and reader using a fixture stream. The rotated-key result kept both thumbprints and returned `Uncertain`. See `.tmp/filecat-efs-recovery-journal-b-tests.xml` and `.tmp/filecat-efs-recovery-journal-b-rotation-tests.xml`. The live job executor, on-disk EFS job admission and recovery UI still need integration and qualification.
