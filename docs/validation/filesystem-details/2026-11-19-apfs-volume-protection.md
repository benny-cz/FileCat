# APFS volume protection in Full Details

Full Details on Apple silicon asks Darwin for the device, mounted BSD source, filesystem type and UUID of the selected item's APFS volume. Disk Arbitration supplies the media encryption properties. FileCat requires the filesystem UUID to agree with Disk Arbitration and resamples the volume before publishing the observation. An incomplete or changed match leaves the status unavailable. The summary issues no Disk Arbitration call. The full-report adapter requests metadata and does not open file contents or a raw disk. [Darwin volume attributes](https://github.com/apple-oss-distributions/xnu/blob/main/bsd/man/man2/getattrlist.2) · [Disk Arbitration description API](https://developer.apple.com/library/archive/documentation/DriversKernelHardware/Conceptual/DiskArbitrationProgGuide/ManipulatingDisks/ManipulatingDisks.html)

The report separates FileVault credential protection from backing-media encryption reported by Disk Arbitration. The observed protection applies to the volume. On Apple silicon, a built-in drive may also encrypt data with a hardware-bound key while FileVault is off. [Apple Platform Security](https://support.apple.com/guide/security/volume-encryption-with-filevault-sec4c6dc1b6e/web) · [Apple encryption detail flags](https://github.com/apple-oss-distributions/libfs/blob/main/FSPrivate.h)

The macOS 27.2.1 arm64 fixture compared the production report with `diskutil info -plist` and a separate Disk Arbitration probe. It checked a plain APFS image, an APFS volume protected by FileVault in another owned image, an APFS volume on encrypted image media, and the Mac's FileVault-protected Data volume. Their raw detail masks were `0`, `2`, `1` and `2`, respectively, with matching volume UUIDs. The report used the source volume for a leaf symlink and the target volume for a file reached through a directory alias. It retained its metadata-only classification. The signed boot snapshot did not provide a usable device match in the separate probe. Intel, other OS versions and encryption transitions on live volumes have separate qualification scope.

The focused Core run passed 74 tests with 13 opt-in or platform skips. The three owned images were ejected.
