## Implementation

Allocated and Hard links are optional column choices; Windows additionally offers Reparse type. Default profile contents and Alt+digit positions are unchanged. The Extra data semantic header is displayed without rewriting a saved profile's stored header. Settings and Analyze share descriptions of scope and limitations.

AppServices injects the platform's qualified `IFileRecords` reader into these producer descriptors. They call only `ReadSummary`, under the same jointly reserved, owned observation lane as details/inventory. Allocated refers to the file/directory object and the reported native scope; it is not recursive contents, exclusive ownership or deletion savings. Hard links requires a regular observation; Windows reparse/unqualified kinds refuse that count. Unknown reparse subtypes have no sort key. No local reader is applied to a remote/archive display path.

Producer applicability is shared between Get/Compute and explicit folder analysis. Only the individually marked metadata-only columns bypass the existing Offline gate; other producers retain it. Folder allocation is eligible. The [result-origin qualification](#analysis-of-result-and-working-set-originals) extends explicit analysis to completed reference panels. Automatic cached context keeps the original subject and device.

Native values expire after the bounded interval, are invalidated on listing generations, and are retired after write jobs. Expiry qualification is cache-only. Expired/last-known values retain useful display text but have unknown sort keys. Sorting retains an immutable set of already produced keys and issues no producer calls.

The column cache retains a bounded display cell rather than the full names inventory. Extra data is projected from the same typed inventory into text, category/scope/time explanation, partial status and an exact key only when complete. Explicit supplementary tabs retain their own full inventory. Retained analysis charges both cell strings and keys against the existing byte/character budget; arbitrary nested objects remain refused. Coverage reports incomplete category inventories separately from successful current observations.

## Analysis of result and working-set originals

Analyze accepts completed results and working-set listings. It resolves each row from the captured `ResultTag`, requires a qualified filesystem origin, and uses its original device for owned native requests. An archive or remote member supplies an unavailable outcome to the retained order. A filesystem original that has disappeared supplies a Gone outcome. The coordinator runs outside the device workers. Cancellation retires the order while any admitted read retains its ownership until it returns.
