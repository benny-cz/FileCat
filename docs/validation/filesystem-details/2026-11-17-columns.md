## Implementation

They call only `ReadSummary`, under the same jointly reserved, owned observation lane as details/inventory. Allocated refers to the file/directory object and the reported native scope; it is not recursive contents, exclusive ownership or deletion savings. Hard links requires a regular observation; Windows reparse/unqualified kinds refuse that count. Unknown reparse subtypes have no sort key. No local reader is applied to a remote/archive display path.

Producer applicability is shared between Get/Compute and explicit folder analysis. Only the individually marked metadata-only columns bypass the existing Offline gate; other producers retain it. Folder allocation is eligible. Native-column Analyze remains disabled in result/working-set panels until their explicit-analysis adapter is qualified. Automatic cached context keeps the original subject and device.

Native values expire after the bounded interval, are invalidated on listing generations, and are retired after write jobs. Expiry qualification is cache-only. Expired/last-known values retain useful display text but have unknown sort keys. Sorting retains an immutable set of already produced keys and issues no producer calls.

The column cache retains a bounded display cell rather than the full names inventory. Extra data is projected from the same typed inventory into text, category/scope/time explanation, partial status and an exact key only when complete. Explicit supplementary tabs retain their own full inventory. Retained analysis charges both cell strings and keys against the existing byte/character budget; arbitrary nested objects remain refused. Coverage reports incomplete category inventories separately from successful current observations.
