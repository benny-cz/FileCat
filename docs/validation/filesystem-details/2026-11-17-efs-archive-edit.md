The ZIP content provider also checks the index's held source before extracting a member for an edit. The reviewed native ZIP route makes the same held index check in addition to its existing native outer archive admission. Ordinary ZIP viewing uses its existing path.

Commit and Save Copy refuse a currently EFS-encrypted working file before writing a snapshot or temporary payload. Native sessions check the held working handle in the private edit namespace. Legacy commit and Save Copy hold the file while checking it, and the local content provider's own handle is checked in Save Copy. Read-only review continues to recognize the existing file.

## Temporary output and recovered Save Copy

Working-file and capture writers now check the actual opened temporary file before the copy loop reads any payload and again before each write. Windows native capture also checks the held file and its download-mark stream during verification. A recovered native capture checks the retained payload and its mark before hashing, during guarded reads and again after the complete review. Recovery identifies a protected capture as needing review and keeps it. Recovered Save Copy checks its actual native output when created, during writes and at verification.

Five new medium-integrity Windows 11 x64 NTFS cases passed. The legacy and native-backed live Save Copy captures refused a temporary file that inherited EFS from its parent. Both left their working file unchanged and removed the temporary folder. Recovered Save Copy refused a snapshot encrypted before review and the same change made after the destination stage was created. The initial refusal left no intent or destination payload. The later refusal kept the intent, and any destination artifact had zero length. A separate encrypted destination fixture refused the inherited stage before payload and kept its intent. All three kept the verified capture's bytes and wrote no saved copy. The wider Windows run passed 466 cases with 16 fixture-specific skips. Ubuntu passed 630 edit cases with 31 skips, and macOS passed 628 with 33 skips. See `.tmp/edit-efs-output-r3.log` and `edit-efs-output-core.trx`.

These checks qualify the observed source and stage boundaries. Active Save Copy's final destination replacement and broader protection-drift and filesystem cases still require qualification. The checks take samples on held handles during the operation.
