OPEN_REPARSE_POINT. Extended absolute paths preserve exact final names. Group/DACL/label are not requested.
Buffers, descriptor ownership, errors, account-name retries and SID_NAME_USE are bounded and typed. NTFS with
persistent ACLs needs no provenance note; other or unknown storage reports the actual OS owner with a note.
There is no Everyone suppression or inference from a cleared persistent-ACL bit. ARM64 stays unavailable.

Owner is optional in the Windows chooser at 160 units; default profiles and settings schema stay unchanged.
Shared field descriptions serve both the Add-column note/help text and Analyze chooser. Windows Owner analysis
is offered and accepted only for filesystem panels, with validation before sort or read side effects.
Gated memory-only inspection now reports an already admitted read as Pending, without scheduling another read.
