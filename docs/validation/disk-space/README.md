The Windows suite includes nine native cases and three reparse-tag classification cases. Native fixtures cover hard links, junction exclusion, queued ancestor movement, explicit hard-linked file roots, metadata access while primary content reads are denied, duplicate/contained roots in both selection orders, denied metadata with readable siblings, and exact native DOS-reserved/trailing names. The denial fixture uses an explicit native ACE because the managed Deny-rule constructor strips SYNCHRONIZE. Mac fixtures cover no-follow enumeration, ancestor movement, explicit hard-linked file roots, root overlap and unreadable-directory sibling continuation. Failure may occur before recursion on macOS, so counters distinguish metadata failure from a failed requested enumeration. These are development regressions, not the full filesystem, cloud, race or resource qualification matrix.

The [schema-1 stream codec](../../design/FILECAT_DISK_SPACE_INVENTORY_SCHEMA.md) preserves tagged raw names and historical root text, enforces typed order and strict schema/resource bounds, verifies a mandatory SHA-256/count trailer, validates relationships and recomputes all four metrics with checked arithmetic. Every load is imported, unverified and inert. Tests include updated-checksum poisoned records, invalid encoding/numbers/enums, cycles and references, aggregate overflow, truncation, duplicate properties, depth/line/file bounds, fragmented nonseekable input and shared-memory refusal/release. The separate native private-publication foundation is described below. Named save/history, catalog, comparison and export/import UI remain unfinished; this codec is not a security-gate qualification.

The [private-store foundation](../../design/FILECAT_DISK_SPACE_PRIVATE_STORE.md) now creates owner-private native storage, retains no-follow directory/file capabilities, streams through the strict codec with the 8 GiB cap and specified free-space reserve, and atomically creates new names. NTFS source-handle rename and APFS source-descriptor clone pass actual native create/reopen, Unicode-name, conflict-preservation, interruption and privacy/link refusal controls. The Mac controls exposed and fixed ACL absence/error ambiguity, the Apple Silicon variadic creation ABI and the Darwin capacity layout. Existing stat-helper clients also passed targeted regressions. Post-publication sync failures are explicitly uncertain; replacement and path fallback are absent. Linux implementation, process-death/orphan cleanup, scratch budgets, native UI and the broader persistence gate remain unqualified. [Source and binary provenance](source-manifest-r22.json) records the tested working tree and verified guest bundle. These CLI tests started no FileCat GUI instances and all runners exited.

[Shared I/O ownership](../../design/FILECAT_DISK_SPACE_IO_OWNERSHIP.md) now covers preparation, containment, cursor creation/read/disposal and backend cleanup with eight global request reservations and one operation per device key. Prepared sources and late arrivals after view disposal close on workers. Cancellation retains actual native ownership, while canceled queued handle releases at application shutdown use a single bounded close worker with the same admission. Seven controls verify worker affinity, cancellation, cross-scheduler serialization, capacity and shutdown without duplicate close. The native Mac run exposed a blocking test barrier; its asynchronous replacement and worker-side reservation release pass on Windows and Mac. [Current provenance](source-manifest-r23.json) includes this checkpoint. Preparation cancellation/status, physical-device qualification and the wider resource matrix remain open.

Raw display now exposes invalid Unix bytes and unpaired UTF16 units, escapes trailing name characters and distinguishes literal backslash sequences. Text predicates on names or paths that lack lossless text return Unknown; they do not match replacement characters. Logical-size uncertainty is independent of allocation: a zero-length file remains zero even when allocation is unavailable, while missing logical size is labelled Unknown in rows, tooltips and the inspector. Exact detail values remain integer byte counts.

Detailed allocation now records directory self-allocation as independent non-file facts; Standard does not request them. Native hard-link/junction fixtures execute both presets on Windows and Mac. Object-fact indexing survives interleaved directory facts and allocation-only conflicts. Root-only namespace filters retain directory allocation, while file-name/type predicates omit those non-file buckets. Directory charges without observed identity remain labelled unverified. Independent streams/forks/xattr coverage and enrichment revisions are still unqualified; the preset does not claim full physical accounting.

Traversal boundaries now have exact typed counters separate from issue severity/exclusion totals, including after the detailed issue cap. The strict inventory coverage record preserves and validates these counters. Finished temporary analyses and unsaved marks/baskets require Keep open / Stop and close review with the preserving default; tab captions are never reused after closing a middle tab. These behaviors pass headless interaction checks, with native desktop input still pending.
The presentation tests draw Treemap, Sunburst and Table at 1180, 600 and 380 DIP in all seven themes, at a fixed height of 780 DIP. Separate cases check 380 × 430 with 20-DIP text and 4,000 virtualized rows, keyboard opening of details and custom overlay cancellation, root-separated incompatible allocation, uncertain predicates, captured timezone, and frozen membership. The [render directory](renders) contains selected images. Broader text/DPI, actual desktop, tooltip and assistive-technology qualification remain outstanding. Headless rendering does not establish native UI acceptance.

Root containment is a request to the held native sources, not a string-prefix proof. A covered root records its active binding and relative observation scope. Unverifiable overlap is excluded with partial coverage instead of being counted twice. Selection leases retain the exact published revision and frozen real members; neither these leases nor historical binding fields are operation approvals.

The CLI suites start no FileCat application processes. A separate [native desktop harness](../../../tests/FileCat.NativeAcceptance/DiskSpaceHarness/README.md) now opens the real window with generated sources and a separate profile. On Mac, a narrow startup/close test recorded 1180 × 763 DIP at 2× and preserved all 509 generated regular paths. It did not start a scan or exercise desktop input, and is not desktop/a11y acceptance. The Windows attempt could not activate windows or obtain accessibility; captures showed only background/lock-screen content, and the user unlock check is pending. Its owned process was closed. Mac checks after its test found no FileCat instance; Ubuntu was left alone. Disposable-machine connection/account notes remain in ignored local files.
