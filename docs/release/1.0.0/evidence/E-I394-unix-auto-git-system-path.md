# E-I394 — automatic Git badges must not execute a writable-PATH replacement

2026-10-12 CEST. **High; remediated preliminarily at exact pushed `40d16db99fb3cf98c29c8f2e34f3c718508d82b5`.** `GitStatusReader` looked up its automatic badge helper through absolute PATH entries. A fully qualified directory need not be system-owned. Ordinary folder browsing could therefore run a replacement Git program from a writable entry when the environment supplied one. No untrusted repository or network destination was needed for this repro; no malicious software on the test machines is alleged.

An isolated probe compiled the actual `GitStatusReader.cs` production source, with only a Windows-specific icon-path stub unused on Unix. On disposable Ubuntu and physical Mac arm64, an owned repository initialized with `/usr/bin/git` and an owned executable named `git` first in PATH made the original `ReadAsync` run the replacement twice. Its marker contained two `owned-git-ran` lines and the synthetic sample was falsely reported as `None` (clean). The paired corrected-source probes selected `/usr/bin/git`, left the marker absent, preserved an available snapshot and reported the sample `Untracked`. Each of four payloads and results matches the guest-side SHA-256 receipt; the owned Ubuntu and Mac probe roots were removed and independently checked absent. There was no workstation UI, real network or external repository.

Automatic badge discovery now uses conventional OS installation locations (`/usr/bin/git` or `/bin/git` on Unix; Git under Windows Program Files). Explicit caller-supplied executable paths and the separate explicit PATH lookup retain their behavior. The focused Windows Git-status class passes **11/12 with one explicit platform skip**. The full headless Windows Release App suite passes **1,636 cases, 36 explicit skips, zero failures**. The full Release solution build has **zero errors and 168 warnings**, including NuGet vulnerability-index warnings because that service was unreachable during this build. The native probe compiled the exact product source with a stub, not the whole App; installed UI, symlink/path-identity races, nonstandard Git locations and candidate qualification remain open.
