# E-I494-MAC — root-started picture-worker identity on the owner's Mac

2026-10-15, exact `main` commit `8fe93efe84a53d6b677ffc4aa805105cfbe4521f`. This is a **native Mac follow-up** to the [Ubuntu root control](E-I494-unix-worker-root-identity.md). First, the existing `FileCat.WorkerProbe` invokes the product's `UnixWorkerIdentity.Drop` and tests root-only file access. Then a self-contained publish of the actual `FileCat --picture-worker` entry point decodes PNG under sudo and demonstrates refusal before reading stdin when no requesting user exists. Neither is an installed FileCat window or release candidate. No stable GO follows.

The host published `FileCat.WorkerProbe` self-contained for `osx-arm64`: 194 files, 94,468,230 uncompressed bytes. The 195-member ZIP (including the per-member hash manifest) is SHA-256 `923eb5f7119ecdc9a23a7ad50272f047974b2a25abde08fa7896cd9fa25c30f8`; the Mac received the same hash and passed `unzip -tq` before extraction. Its extracted `FileCat.Core.dll` SHA-256 `cf1754df4ce927cbe042d891f3d02c45ab6d639b169cca9146438062274e9900` and probe SHA-256 `1e5079382f2bf6940ee190e67aa7f3163519f8de77f25928587d38bc14f74c13` match the local package. The Mac ran macOS 27.0.1 on ARM64, with requester `benny` UID 501/GID 20. The sudo credential was supplied to the SSH session through stdin, never embedded in a command, package or evidence file.

One synthetic file was created in `/var/tmp` as `root:wheel` mode `600`. The bounded script checks the actual owner/mode and runs three controls:

| Start and input | Native observation |
|---|---|
| Ordinary `benny`, owned readable file | `501:20 → 501:20`; ordinary file read succeeds. |
| Root through sudo, root-only file | `0:0 → 501:20`, `regainRefused=True`, no refusal; reading the root-only file throws `UnauthorizedAccessException`. |
| Root with `SUDO_UID`/`SUDO_GID` cleared, root-only file | Drop returns the explicit “no ordinary user to become” refusal at `0:0`. The **probe deliberately continues to read** the sentinel to show the authority that would exist if decoding proceeded; the product worker instead returns on this refusal before decoding. |

The script's assertions pass. Its trap removed the root-only fixture; an independent SSH check found it absent and no probe process running. After the raw outputs and inputs were sealed, the owned Mac extraction directory and transferred ZIP were removed with their exact resolved path checked; the cleanup receipt confirms both absent. No Mac power, SSH or system setting was changed for this run.

Both return exit 0, `FCPX`, 2×2 dimensions, one frame, PNG format and 16 decoded pixel bytes.
