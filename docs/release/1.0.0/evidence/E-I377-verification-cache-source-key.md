# I377 — delimiter collision reuses a stale verification result

2026-10-12 CEST. **High verification-integrity issue; remediated preliminarily in a declared local product/test overlay.** The result cache joined a path and sidecar name/size/time tuples with unescaped `|`, `:` and `;`. Unix filenames may contain these characters. One sidecar named `a.sha256:75:638423424000000000;b.sha256` with size 75 and modified time 638448480000000000 produces the same version-3 key as two sidecars `a.sha256` (size 75, time 638423424000000000) and `b.sha256` (size 75, time 638448480000000000). The file path, size and time need not change. This is independent of the folder/file comparer corrections in [I374–I376](E-I376-windows-case-sensitive-sidecars.md).

A one-case synthetic regression fails on exact pushed `63fa80344614e02c8573a0b83e0f47b553ac391e` product code: the two distinct source sets have equal result keys.
