2026-10-12 CEST. **Preliminary correction at `e353eba`; candidate and wider I08 containment remain open.** `RestrictedProcess` built the Windows picture worker's Unicode environment from every parent variable. Its low-integrity token and job limits did not remove inherited environment values.
