# I374 — case-distinct Unix folders shared verification sidecars

2026-10-12 CEST. **High verification-identity issue; remediated preliminarily in a declared local product/test overlay.** The folder-sidecar cache introduced by the earlier verification implementation keyed directory paths with `OrdinalIgnoreCase` on every platform. On a case-sensitive Unix filesystem, `source` and `SOURCE` are distinct directories. When their directory timestamps matched inside the cache freshness window, scanning the second could reuse the first folder's parsed checksum claims. Its eviction filter used the same case-insensitive comparison. This finding is separate from I373's unbounded retention; the 512-folder bound remains unchanged.

The native Ubuntu VMware probe ran against exact pushed `bafaf4c618e68d828a33714869ba150ca13284c5` Core code. It created only an owned fixture with two distinct directories, distinct complete file bytes and matching directory timestamps. Each file's own `.sha256` claim matched its actual bytes. The first automatic check returned `Matches`; the second returned **`Differs`**, and the parsed sidecar object's `Folder` was the lower-case path. The raw probe exit was **2** and its owned fixture was absent after cleanup. This establishes a wrong cross-folder verification result, not a corrupted source file or a physical-device observation. The initial inline VM launcher reported a malformed `0n` exit marker; a corrected fixed launcher was run afresh and independently recorded the actual exit 2. Two attempted probe builds failed before a product run because the repository dependency lock rejected the standalone project reference; their logs remain failed. The self-contained baseline was then built from the already compiled exact Core DLL without modifying the repository lock.

The correction uses `PathUtil.SafetyComparer` for both the folder dictionary and the eviction exclusion: case-insensitive on Windows, ordinal on Unix. The same self-contained probe rebuilt with the corrected Core code returned `Matches` for both files, parsed the upper-case folder for the second, exited **0**, and removed its owned fixture. Both raw outputs contain the two actual and expected SHA-256 values, the distinct-directory and equal-stamp controls, and fixture-absence result. An independent reader reparsed both nested JSON results and exit files, compared both payload hashes, checked original Git and corrected source predicates, and rehashed the probes and launchers. This is a local native component observation at a declared overlay, not installed-app, physical-source or candidate qualification.
