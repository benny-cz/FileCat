# E-I488 — Windows volume selection includes backing-disk length

At exact `54ae0b3281229c9a7cbeb953454525a72c5754d9`, a Windows volume selection recorded its backing PnP interface and storage GUID but omitted disk length. A different-sized replacement that reused both strings could therefore compare equal at the selection gate. This is a bounded source-confusion gap within I106, separate from I487's earlier omission of the entire selected identity.

The same compiled test assembly (SHA-256 `86385520629ee1cf1ccc6371a42731c6d5f39a700e87a4f63334490e9f41bcf2`) ran in the disposable Windows VM against the parent Platform DLL and the corrected DLL. The parent case failed **0P/1F** because the same-interface/same-GUID 64 MiB and 128 MiB records produced equal identities. The corrected case passed **1P/0F** after disk length was added in invariant decimal form; unavailable or zero length now refuses an identity. The two Platform DLL hashes are `dc75182099671a5205151e0c690a28c05ae192f61bc33f6288d4b311668c7e4d` and `89ab4c1cc60dc307d236a4afe4ef108ee1ecbb62ae85e5f150643bbaba58adda`.

A fresh owned 128 MiB NTFS VHD at VM `R:` passed the existing native volume-bind positive **1P/0F** without a source-content read. It was detached; its 10,514,432 bytes have identical guest and host SHA-256 `2cd9f039dc7a8c73062729c2e5c400f1ed22b6caf64327c7a9d2023ae0a7f88d`. The corrected App drive-letter replacement refusal also passed **1P/0F** in the VM. A zero-error Release solution build passed. The background VM's complete Platform run produced **392P/35 explicit skips/4 PageView failures** because those four UI cases received `Invalid window handle (0x80070578)` under VMware Tools. The separate run excluding only that class passed **392P/35S/0F**. A host VSTest attempt aborted before testhost connected and contains no case result. The VHD setup script exited nonzero while trying to hash the *attached* VHD after diskpart had succeeded; the post-detach guest/host hash and cleanup receipts are retained. None of these infrastructure outcomes is relabelled as a pass. All five owned guest test directories were removed after results were retrieved.
