## Contained correction and native recheck

`Wildcard.IsMatch` keeps its allocation-free ordinary path. Only after a failed glob match with non-ASCII in both name and pattern does it retry their Unicode Form C spellings. This preserves ASCII behavior and explicit regex semantics while making composed and decomposed filenames match the same literal glob. An invalid UTF-16 value cannot gain a match from normalization. Include and exclude use the same matcher. The corrected Windows Release `MaskTests` class is **44 passed / 0 failed / 0 skipped**, with a zero-warning/error build; the same class on macOS passes **44/0/0**.

The Mac validation worktree at `241c8841` applied only the two product/test files from patch SHA-256 `cd8c8f71f43872a60f7b043bf5015779793b50582bacd4ccd90aa6aca9d98870`. `eng/package-macos.sh` produced a dirty-source-identified, ad-hoc-signed package ZIP SHA-256 `934764e2ede4137dbfe4ea50d7bad2371d67c97da7d6469ace8d8a9fb35e4e1e`; `codesign --verify --strict` passed.
