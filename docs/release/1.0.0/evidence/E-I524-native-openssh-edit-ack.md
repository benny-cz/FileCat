# E-I524 — native OpenSSH F4 edit acknowledgement

The strict F4 edit-session path now has an actual-server headless regression in addition to the older in-memory SFTP case. The new test starts a fresh user-mode OpenSSH `sshd` on loopback with owned generated keys, pins that server's host key in FileCat's isolated state, opens its folder in a panel, edits `remote.txt` through F4, explicitly commits, and requires all three results: a completed copy job, exact edited bytes on the server, and a **persisted `Unchanged`** edit-session record. A failed acknowledgement reports job state, pending commit owners, I/O shutdown and the last notification. It does not turn an uploaded file into an acknowledged session merely because bytes arrived.
