# E-I521 — ordinary Linux recovery with an authorized process census

At exact pushed source `b6169a1744eaeb39c35f420fdbf1d7c1614ce89d`, FileCat keeps the fail-closed ordinary-user process check. If an ordinary Linux account cannot identify all local executables, it asks PolicyKit to launch a narrow root helper that repeats the complete census and returns only `running` or `clear` with a random 128-bit request nonce. Unknown, cancellation, timeout, malformed output, or a persistent inaccessible executable still refuses recovery. The helper neither opens a recovery device nor starts the GUI.
