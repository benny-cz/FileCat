## Medium

F-M3 (C5) is now F-H9 above.

- **F-M1 (C3).** The destination review (a full read and SHA-256, up to 64 MiB) runs before the conflict answer or policy applies (`Executors.cs:685, 971`; `StreamTransferExecutor.cs:348`). Skip and Keep both therefore read every existing destination, and each replaced file is read three times.
- **F-M2 (C4).** `TreeCompare.cs:142-145` does not charge failed captures to the 256 MiB comparison budget. Each one-sided folder over 64 MiB reads up to 64 MiB on every Compare, outside the device scheduler and its stop check. Source-side items share the budget, so many new source files can make Mirror silently keep target-only items.
- **F-M4 (C6, W6).** Windows permanent folder delete now runs through `SecureFileOps.DeleteTree`. Read-only files inside the tree are deleted silently (`IgnoreReadOnly`) without the old confirmation, and a child that antivirus or the indexer holds open fails at once, with no retries. `DeleteTreeBound` catches nothing: `IOException`, `UnauthorizedAccessException` and `Win32Exception` from `Walk`, `ToVolumePath`, `GetBasic` and `List` fail the whole job, and the remaining roots are skipped with no Retry or Skip.
- **F-M5 (P3).** The two new Markdown tests cannot fail (`HtmlPageTests.cs:89-91`, `MarkdownTests.cs:13-15`). Their hostile line is rejected in 0 ms by the regex the commit replaced. FCSEC-038's own trigger takes 1.08 s at 64K, under the tests' 5 s limit, so restoring the vulnerable regex passes both. The SFV tests do discriminate.
- **F-M6 (P4, W8).** ZIP add now holds each source with read sharing only (`ZipUpdateExecutor.cs:478` → `LocalIconFileLease.cs:36-37`). A file another process has open for writing (a live log, a database, a download) fails as "contains a link or cannot be held", and one such file aborts the whole Pack or Add. Any junction or mount point on the source path is refused the same way.
- **F-M7 (P5).** `Ntfs.cs:19-20, 259, 273-278`: the caps of 100,000 compression units per file (≈6.1 GiB) and 250,000 per scan (≈15.3 GiB, in MFT order) turn later legitimate compressed files into name-only results. The previous per-file limit was 10 million units.

## Low

- **C7.** F2 rename with a Replace answer still calls `Fs.Move(src, dst, replace)` without a destination review (`Executors.cs:2049-2067`). It is narrowed by the UI pre-check but not closed. **Fixed** in `e07f1156`.
- **C8.** The bound replace renames through handles without write-through, dropping the contract "replacing always writes through" (`Executors.cs:1174`). After a power loss, a cross-volume Move's data may survive only under the staged name, which interrupted-job review offers to delete. Plausible. **Fixed** in `c448db09`.

- **P7.** The mDNS per-datagram budget counts label bytes, not allocations: about 20–45 MB of transient allocation per datagram. Plausible. **Fixed** in `5d57e89d`.
