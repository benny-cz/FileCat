# E-I421 — bounded Unix owner and group name caches

2026-10-13 CEST. **Preliminary I06 resource correction; no whole-process memory or release-candidate claim.** Exact preceding source is `43d3a792617b8565179e90479b7bce0190c15f81`. `UnixPermissions.UserName` and `GroupName` each held a process-lifetime `ConcurrentDictionary<uint,string>`. Files from removable or remote filesystems may have arbitrarily many owner/group IDs that the local account database cannot resolve. The old caches retained one numeric fallback string per distinct ID without a bound. The correction keeps a separate recent-name cache for each lookup, capped at **256 entries and 32,768 retained UTF-16 characters**; it performs NSS lookup outside the cache lock, rechecks on insertion and does not cache a single oversized name. This bounds these two cache stores, not libc/NSS allocation or the process as a whole.
