# I601 — Windows right-click Properties opens no sheet

## User consequence and route distinction

The owner reports that **Alt+Enter opens Properties** on Windows, while **right-click → Properties does nothing** for a local folder. The report applies to ordinary local folders; no exact pre-fix package or path was supplied. The two actions use different code routes: Alt+Enter calls `MainViewModel.ShowPropertiesForPath` with FileCat's persistent native owner. The Windows right-click menu is constructed and invoked in the short-lived `WindowsContextMenu` Shell-extension host, which used a hidden temporary 1×1 owner and destroyed it immediately after a successful `IContextMenu.InvokeCommand`. That lifetime is a plausible explanation for a property sheet that fails to appear; it is not a captured pre-fix UI trace.

The separate I589 macOS/Linux Properties fallback is accepted at its recorded scope. This is a Windows Shell-menu ownership boundary, so it does not reopen the Mac/Linux case.
