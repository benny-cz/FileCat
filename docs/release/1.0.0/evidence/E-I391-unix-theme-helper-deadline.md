# E-I391 — bound the automatic Unix icon-theme helper

2026-10-12 CEST. **High automatic-startup availability defect, remediated preliminarily.** On Linux, [app initialization](../../../../src/FileCat.App/App.axaml.cs) creates the freedesktop icon source synchronously. `FreedesktopIcons.Gsettings` read redirected stdout to EOF before calling `WaitForExit(2000)`. A stalled `gsettings` or a child retaining its output pipe therefore bypassed the intended two-second wait and could hold startup. The selected binary is the fixed system path `/usr/bin/gsettings` or `/bin/gsettings`; this finding concerns its lifetime, not PATH substitution or evidence of a malicious system tool.

A time-parameterized internal query seam copied the original wait order without changing its behavior. An owned Ubuntu x86_64 shell helper wrote its PID, then executed `/bin/sleep 5` without closing stdout. The original-behavior test requested a **500 ms** deadline but finished **Failed after 5.121 s**, returning the empty string instead of declining the stalled result. The raw exit code, TRX and log are retained. This is a controlled helper, not an observation that the installed `gsettings` stalled in ordinary use; the original Git source and exact baseline binary are retained, although the intermediate baseline source overlay was not byte-snapshotted before correction.

The correction waits for process exit before reading output, kills and briefly reaps a still-running process tree on timeout, then gives EOF reading its own finite 250 ms bound in case another process holds stdout. Nonzero exit and start/read failures still produce no theme choice. A healthy helper's quoted `Adwaita` output remains `Adwaita`. The product call keeps its two-second process deadline; the 500 ms value belongs only to the adverse test.

The paired corrected Ubuntu run passes **four of four** icon-theme class tests in 0.931 s, including the stalled PID's absence and the exact healthy result. The physical Mac arm64 run passes **three**, with one existing Linux-desktop rendering case explicitly skipped; both new helper controls pass. Each native run uses .NET **10.0.12** and independently matching transport, Core assembly and TRX hashes. The full Windows Release Core suite passes **4,029/103 explicit skips/zero failures**; the two Unix helper controls explicitly skip there. Full Release solution build has zero errors (41 existing warnings). Guest test roots and named files are removed; Mac's resolved owned test root is absent. No workstation UI, physical source, installed FileCat UI, settings or account changes were used.

This bounds a synchronous optional theme lookup and retires its live root on timeout. It does **not** establish a Unix process sandbox, cleanup of an already detached descendant, whole-app startup latency on every desktop, or exact-candidate acceptance. I08 and broader I16 remain open; I106/I110 physical-source validation remains on HOLD and stable 1.0.0 still requires explicit human GO.
