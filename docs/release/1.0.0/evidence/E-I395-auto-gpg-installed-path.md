# E-I395 — automatic OpenPGP checks must not execute a writable-PATH replacement

2026-10-12 CEST. **High; remediated preliminarily at exact pushed `6de6fc69394eb4104c6f4248ce06ba54c9823ba5`.** `OpenPgp.Tool` preferred the first absolute PATH entry containing `gpg`/`gpg2`, including writable directories. Automatic sidecar verification would then run that program under the FileCat user's account and interpret its status lines. The probe used an owned replacement, an invalid synthetic signature and an isolated keyring; it did not use a real account, key or network server.

The exact pre-change Core build at the `4a69ba89` documentation checkpoint ran the harmless owned `gpg` from a writable PATH entry on disposable Ubuntu and physical Mac arm64. The Mac has no conventional GnuPG installation; the corrected run selected none, left the marker absent and reported unchecked. Explicit internal lookup remains separate.
