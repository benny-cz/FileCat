# E-I455 — bounded, nonblocking Linux sysfs reads

**Scope:** High availability and memory safety in I06/I106. At exact parent `f0c7c4013b5208cd42ecb51ab20f99b8b747d3c6`, Linux disk discovery used `File.ReadAllText` on each sysfs value. An owned 4 MiB `size` file made the actual parent Core control allocate **16,851,528 bytes** and fail its 1 MiB budget (**0P/1F**). On ordinary-user Ubuntu, an owned FIFO substituted for `size` stalled the exact-parent product test until the external eight-second controller killed it (**exit 124; no TRX**). Both baseline failures are preserved separately.

The correction opens Unix sysfs values with `O_NONBLOCK|O_CLOEXEC`, rejects nonseekable descriptors, and limits each opened value to **4,096 bytes plus one EOF probe**. Invalid or oversized disk sizes remain unavailable, so the device is omitted rather than inventing a size. Windows test fixtures use the same opened-byte bound. The final Windows Unix-device class passes **7P/17 explicit platform skips/0F**. A read-only Ubuntu probe found 16 real `/sys/block/*/size` descriptors seekable and 4,096 bytes by `stat`, with short readable values. The Release solution build has **zero errors/42 warnings**.
