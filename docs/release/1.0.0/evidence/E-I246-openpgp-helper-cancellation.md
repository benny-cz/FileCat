# I246 — OpenPGP helper cancellation observes the caller before launch and during its wait

`OpenPgp.Verify` previously started an available helper for an already cancelled caller and used a blocking sixty-second process wait before observing cancellation. A helper that had completed its status output could therefore keep the call waiting until its natural exit. The correction checks the existing caller token before starting an available helper, then waits asynchronously with that token under the same sixty-second limit. The existing helper kill, timeout result, output interpretation and missing-GnuPG policy remain. Severity is Low–Medium for helper responsiveness and unnecessary owned process work; these controls establish no ordinary GnuPG or security-boundary incidence.
