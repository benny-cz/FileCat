# Dependency notice manifest fixtures

These are the five actual self-contained RID manifests and two retained Windows framework-dependent manifests used by the preliminary [notice qualification](../../../../docs/release/1.0.0/evidence/E-I03-NOTICES-pinned-full-texts.md). `index.json` pins each original byte sequence and its qualification proof. They cover metadata admission; they do not execute or qualify those packages or settle license eligibility.

The validation script checks all seven unchanged manifests and eight controlled identity changes per manifest. Update and requalify the actual fixture inputs when dependency/runtime versions change. Keep original failed observations in release evidence.
